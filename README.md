# OMFS In-House VSP

Site du projet **OMFS Planner**, un add-on Blender gratuit et open source pour la planification chirurgicale maxillo-faciale,
avec des tutoriels Meshmixer et des fichiers STL à télécharger.

Créé par Thomas Lafontaine-Giguère, DMD. Site : https://thomaslgiguere-tech.github.io/Meshmixer-project/
